# Recommendation V5.2 budgeted roadmap hardening

This document records the execution contracts that supersede the first preparation drafts in PR #39.

## Cost control

All model training is one-shot GitHub Actions only.

- training-process hard limit: 20 minutes;
- total self-hosted job timeout: 30 minutes;
- timeout is a failed experiment, not permission to increase the budget;
- no direct VPS training;
- request files are created only to trigger one intended run and are deleted from the PR branch immediately after that run is created.

## Authoritative Behavioral refinement workflow

Use:

`.github/workflows/recommendation-behavioral-v5-2-refinement-budgeted-v3.yml`

Do not use the earlier refinement preparation workflows.

The v3 contract preserves the schema expected by the existing refinement runner and then applies a deterministic normalization pass.

Candidate coverage is variant-independent because every variant uses the same immutable MATCH sample. The original refinement runner calculated it only on Behavioral-eligible rows, which made the metric trivially 1.0. The normalization pass replaces it with the candidate coverage already measured correctly on the complete pinned sample by the source V5.2 architecture sweep.

The refinement summary must therefore contain:

- `executorVersion = CANDIDATE_COVERAGE_FIXED_2`;
- `refinementContract.candidateCoverageSource = PINNED_SAMPLE_SOURCE_SWEEP`;
- the exact source candidate coverage;
- no FUTURE_TEST rows;
- no full-training or Value authorization.

## Authoritative bounded Value workflow

Use:

`.github/workflows/recommendation-value-v8-bounded-v5-2-v2.yml`

Do not use the earlier V5.2 bounded Value preparation workflow.

Before any Value model update is allowed, the v2 workflow streams the complete Behavioral V5.2 propensity artifact and verifies:

- exact artifact SHA-256;
- exact Dataset V6 SHA-256 on every row;
- Behavioral V5.2 schema/model/feature versions;
- raw within-decision softmax probabilities;
- candidate probabilities are strictly positive and sum to 1;
- observed probability equals the candidate raw probability;
- no Behavioral propensity floor;
- TRAIN rows are OOF and have match exclusion metadata;
- TUNING rows are generated by the full-TRAIN model;
- no FUTURE_TEST propensity rows exist.

Only after the full-stream audit passes does the bounded Value V8 diagnostic start. Value applies observed-propensity stabilization and importance-weight clipping exactly once inside action training.

## Remaining sequence

1. Initial budgeted V5.2 architecture sweep.
2. If and only if architecture continuation passes, exactly one v3 refinement.
3. No-training full-readiness/cost report.
4. Full Behavioral V5.2 only under an explicit one-shot authorization and the existing 20/30 minute hard limits.
5. No-training V5.2 Value input-readiness report.
6. Bounded Value V8 using the v2 full-stream-audited workflow.
7. Offline verification only after bounded Value PASS.
8. Stop. Full Value V8, passive shadow, randomized canary, and production ranking remain outside this authorization.
